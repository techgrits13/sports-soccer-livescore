🌐 RENDER DEPLOYMENT
================================================================================

1. Create new Web Service on Render.com
2. Connect your GitHub repo
3. Set root directory: backend
4. Add these environment variables:
   - SUPABASE_URL
   - SUPABASE_KEY
   - LIVESCORE_API_KEY
   - API_FOOTBALL_KEY
   - NODE_ENV=production
   
   (See .env.new for full list)

4. Deploy!

# 🚀 Quick Start - Sport Soccer Livescore

## Your App is Ready with Real Data! 🎉

Your SportMonks API key is already integrated. Just follow these steps:

### Windows Users (Easiest):
```bash
cd backend
quick-setup.bat
npm install
npm start
```

### Mac/Linux Users:
```bash
cd backend
chmod +x quick-setup.sh
./quick-setup.sh
npm install
npm start
```

Then in a **new terminal**, start the app:
```bash
npx expo start
```

## ✅ What You Get

- **Real Live Data** from SportMonks API (3,000 requests/day)
- **No Mock Data** - everything is real
- **API Dashboard** in Settings tab to monitor usage
- **Smart Fallback** to backup APIs if quota exceeded

## 📱 View API Status

1. Open the app
2. Go to **Settings** tab (⚙️)
3. Scroll to **API PROVIDERS** section
4. See real-time quota usage for SportMonks ⭐
